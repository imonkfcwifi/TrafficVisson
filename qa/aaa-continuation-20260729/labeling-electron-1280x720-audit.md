# TrafficVisson 질문형 라벨링 · 실제 Electron 1280×720 감사

검증 시각: 2026-07-29  
대상: 개발 Electron renderer + 실제 로컬 bridge 복구 데이터  
비교 입력: `concept-vs-labeling-electron-1280x720.png`

## 통과

- 브라우저 목업 프레임이 아니라 하나의 Windows Electron 창으로 표시된다.
- 앱 셸과 질문 화면에 document-level 세로 스크롤이 생기지 않는다.
- 로컬 번들 `SUIT Variable`의 계층, 차분한 청회색 유리 표면, 절제된 파란 강조, 검은색 주요 CTA라는 컨셉 방향을 유지한다.
- 대표 프레임, 실제 미리보기, 질문, 유형, `Y/N/U/E`, 판정 프로필과 진행률이 한 화면에 도달한다.
- 빠른 판정과 정밀 판정 토글이 실제 상태를 바꾸며 프로젝트별 로컬 선호를 복구한다.

## P0

1. 현재는 가져오기, 분석 시작, dense index, AI 명령 실행을 서로 다른 버튼과 화면에서 수동으로 이어야 한다. North Star의 `영상 하나 → 질문 대기` 단일 `PipelineJob` 수용 기준을 충족하지 않는다.
2. `영역 수정 E`는 SAM2 마스크 재생성이 아니라 임시 박스 중심 이동이다. 연결 전에는 완료 기능처럼 표현할 수 없고, 최종 구현은 `한 번 클릭 → SAM2 마스크/추적 → 재확인`이어야 한다.
3. 사용자 승인 뒤 파생 Incident·지도·CSV·증거·DocumentEditPlan 자동 갱신이 한 pipeline provenance로 묶이지 않았다.

## P1

1. 질문 카드 오른쪽 하단의 큰 빈 공간에 GPS 상태, 병합 프레임 범위, 유사 3·4분기 사례 3~5건, AI 추천 심각도 근거가 없다.
2. 첫 화면의 `AI 선라벨 명령`과 52개 영상 수동 선택기는 North Star의 기본 작업 경로를 복잡하게 만든다. 고급 진단/재처리 도구로 내려야 하며 기본 흐름은 현재 PipelineJob의 질문 큐만 보여야 한다.
3. 미분류 장면 설명은 폭이 좁은 단일 줄에서 말줄임되고, 접근성 텍스트에는 같은 설명이 중복 노출된다.
4. 시간축 병합 결과가 늦게 연결될 때 대표 프레임 인덱스가 기존 값에 남을 수 있던 상태 동기화 문제를 수정했다. 회귀 테스트와 실제 병합 질문 시각 검증은 추가로 필요하다.

## P2

1. 상단 영상 전환·AI 명령·질문 본문이 모두 같은 시각적 무게를 가져 핵심 질문보다 도구막대가 먼저 읽힌다.
2. 증거 프레임 영역에 컨셉의 generous whitespace를 적용했지만, 질문 카드의 설명·상태 텍스트는 일부 11px 수준이라 현장 노트북 DPR 검증이 필요하다.

## 남은 재검증

- PipelineJob 질문 대기 상태의 실제 Electron 화면
- 정밀 판정 `Y → 1/2/3` 저장·자동 다음 이동
- 빠른 판정 `Y/N/U/E` 저장·자동 다음 이동
- 낙하물·긴급 강제 질문
- SAM2 마스크 생성·전후 프레임 추적
- 실제 3·4분기 사례 이미지·문구 표시
- 검토 완료 후 지도·CSV·증거·HWPX 미리보기 자동 갱신
